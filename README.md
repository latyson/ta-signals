# [НАЗВАНИЕ] — Telegram Mini App технического анализа

Один файл `index.html` (HTML + CSS + JS, без сборщиков). Котировки берутся прямо из браузера
(Binance, Twelve Data), история хранится в `localStorage` устройства.

## 0. Настройка

Откройте `index.html`, в начале `<script>` заполните объект `CONFIG`:

| Поле | Что вписать |
|---|---|
| `APP_NAME` | название приложения |
| `BOT_USERNAME` | имя бота без `@` |
| `APP_SHORT_NAME` | короткое имя Mini App из `/newapp` |
| `ADMIN_IDS` | ваш Telegram user id числом, например `[123456789]` (узнать: @userinfobot) |
| `REF_URL` | ваша реферальная ссылка |
| `SUBID_PARAM` | имя параметра sub-ID из кабинета партнёрки |
| `PAYOUT` | выплата брокера (0.80 = 80%) → безубыточный винрейт 1/(1+0.8) = 55.6% |
| `TWELVE_DATA_KEY` | ключ Twelve Data |
| `SUPPORT_USERNAME` | ник аккаунта поддержки без `@` (кнопка «💬 Помощь») |
| `AI.API_KEY` | бесплатный ключ ИИ (см. раздел 4) |
| `UNLOCKED_IDS` | id пользователей, которым вы вручную открыли доступ (раздел 6а) |
| `SETTINGS_URL` | `"settings.json"` — файл, который переопределяет реф-ссылку, sub-параметр, поддержку и дополняет список доступа |
| `WORKER_URL` | адрес Cloudflare Worker — бот постит в канал, автопостинг, мгновенная выдача доступа (раздел 7) |
| `GITHUB_REPO` | `"логин/репозиторий"` — для кнопки «Открыть settings.json на GitHub» в админке |
| `LOCKED_FEATURES` | какие функции закрыты: `ai`, `stocks`, `crypto`, `forex_td`, `exp1`, `exp3` |

Самопроверка: откройте `https://ваш-сайт/?selftest=1` — увидите число сигналов и винрейт на
случайном блуждании (около 50%) и юнит-проверки RSI, Bollinger и правила результата.
Предпросмотр админ-кнопок в обычном браузере: `?admin_preview=1` (это только показ кнопок, секретов в приложении нет).

## 1. Деплой

**GitHub Pages**
1. Создайте публичный репозиторий, загрузите `index.html`, `settings.json` (и `README.md`).
2. Settings → Pages → Source: *Deploy from a branch*, ветка `main`, папка `/ (root)` → Save.
3. Через 1–2 минуты сайт будет на `https://<логин>.github.io/<репозиторий>/`.

**Netlify**
1. app.netlify.com → *Add new site* → *Deploy manually* → перетащите папку с `index.html`.
2. Получите адрес `https://<имя>.netlify.app` (можно переименовать в Site settings).

Нужен именно HTTPS-адрес — его вы укажете в BotFather.

## 2. @BotFather

1. `/newbot` — имя и username бота, сохраните токен (в приложение его **не** вставлять).
2. `/newapp` → выберите бота → название, описание, картинка 640×360 → **URL приложения**
   (адрес с GitHub Pages / Netlify) → короткое имя (это `APP_SHORT_NAME`).
   Ссылка на приложение: `https://t.me/<BOT_USERNAME>/<APP_SHORT_NAME>`.
3. `/setdescription` — приветствие, которое видно до нажатия «Start», например:
   «Инструмент технического анализа: RSI, Bollinger, тренд. Не является инвестиционной рекомендацией.»
4. Кнопка меню: `/mybots` → бот → *Bot Settings* → *Menu Button* → *Configure menu button* →
   URL приложения и подпись (например «Открыть»).

## 3. Twelve Data

1. Зарегистрируйтесь на twelvedata.com → *Dashboard* → *API Keys* → скопируйте ключ в `TWELVE_DATA_KEY`.
2. Бесплатный план: 8 запросов в минуту, 800 в день. Приложение кэширует свечи на 60 секунд
   и запрашивает только выбранный актив (2 запроса на анализ: 1min и 15min).
3. **Проверка задержки.** В рабочие часы биржи США откройте в браузере:
   `https://api.twelvedata.com/time_series?symbol=AAPL&interval=1min&outputsize=3&timezone=UTC&apikey=ВАШ_КЛЮЧ`
   Сравните `datetime` последней записи с текущим временем UTC. Отставание больше 2–3 минут
   означает задержанные данные. Приложение делает ту же проверку при старте и,
   если котировки задержаны (или ключа нет/план не даёт акции), скрывает вкладку «Акции»
   с пометкой «нет данных в реальном времени». Результат проверки кэшируется на 15 минут.
4. Праздничные дни биржи США и форекса приложение не учитывает: в такие дни данных не будет,
   и пользователь увидит «Нет данных».

## 4. ИИ-разбор (бесплатный)

Кнопка «🤖 ИИ-разбор» отправляет уже посчитанные цифры (RSI, BB, тренд, уровень, ход) бесплатной
языковой модели и показывает пояснение простым языком. **Направление сигнала ИИ не меняет**,
промпт запрещает обещания прибыли и требует напоминания о риске.

ИИ работает через **бесплатные модели OpenRouter**: `nvidia/nemotron-3.5-lightning:free`, запасные
`google/gemma-4-31b-it:free` и `google/gemma-4-26b-a4b-it:free`. Ответ — 5–30 секунд.

**Ключ в код сайта не кладём.** Репозиторий публичный: GitHub находит ключи в коде, и OpenRouter
сразу их отключает. Поэтому:
- **Админам:** «⚙️ Админка» → «ИИ (OpenRouter)» → вставить ключ. Он хранится только на этом телефоне.
- **Всем пользователям:** подключите Worker (раздел 7) и добавьте в нём секрет `OPENROUTER_KEY`.
  Тогда ИИ-кнопки работают у всех, а ключ остаётся на сервере. Без Worker обычные пользователи
  ИИ-блок не видят.

Как сделать ключ: openrouter.ai → *Keys* → *Create Key* → **Credit limit = 0** (только бесплатные
модели, списать с ключа нечего). Список бесплатных моделей меняется: openrouter.ai/models → *Free*,
имена — в `CONFIG.AI.MODELS` (и `AI_MODELS` в Worker).

**Оценка ИИ «куда скорее»** (кнопка «Спросить ИИ» на экране сигнала) — это мнение модели, а не
сигнал. Она сохраняется отдельно, проверяется по свечам так же, как сигналы, и рядом показывается её
реальная точность на устройстве. В канал оценки ИИ не публикуются.

Ключ лежит в клиентском коде и виден всем — используйте только `pk_`-ключ, никогда секретный `sk_`.
Можно подключить любой другой совместимый `/v1/chat/completions` (например, бесплатные модели
OpenRouter с суффиксом `:free`): поменяйте `AI.ENDPOINT`, `AI.MODEL`, `AI.API_KEY`.
Если ИИ недоступен, приложение пишет «ИИ сейчас недоступен» — на сигналы это не влияет.

## 5. Ссылки под источники трафика (sub-ID)

Параметр `startapp` попадает в `Telegram.WebApp.initDataUnsafe.start_param` и становится sub-ID
в ссылке «Где торговать»: `REF_URL?SUBID_PARAM=<sub-ID>` (без параметра — `direct`).

| Источник | Ссылка |
|---|---|
| YouTube, ролик 1 | `https://t.me/<BOT_USERNAME>/<APP_SHORT_NAME>?startapp=yt01` |
| Threads, пост 1 | `https://t.me/<BOT_USERNAME>/<APP_SHORT_NAME>?startapp=th01` |
| Telegram-паблик 5 | `https://t.me/<BOT_USERNAME>/<APP_SHORT_NAME>?startapp=tgp05` |
| Ваш канал (посты из админки) | `...?startapp=channel` — подставляется автоматически |

Допустимы латиница, цифры, `_` и `-`, до 64 символов. Статистику по sub-ID смотрите в кабинете
партнёрской программы: раздел статистики/отчётов → группировка или фильтр по sub-ID
(название раздела зависит от партнёрки; параметр должен совпадать с `SUBID_PARAM`).

## 6. Админ-режим

Если ваш id есть в `ADMIN_IDS`, появляются:
- под сигналом «📤 Отправить в канал» и «📋 Копировать». Если подключён Worker (раздел 7), пост
  уходит **ботом сразу в канал**; без Worker открывается окно «Поделиться» Telegram;
- после экспирации «📤 Отправить результат» для каждого отправленного сигнала, включая минусы;
  в истории — метки «результат отправлен / не отправлен»;
- «📊 Итог дня» с предупреждением, если у части сигналов результат не отправлен;
- «⚙️ Админка»: статистика (сегодня / 7 / 30 дней / всё время, разбивка по активам),
  бот и канал (автопостинг вкл/выкл, тестовый пост, итог дня автопостинга), ручная выдача доступа,
  реф-ссылка и генератор ссылок под источники трафика.

Проверить, видит ли приложение вас админом: «Как это работает» → внизу строка
`Telegram: v… · ID: … · admin`.

## 6.1. Перевес индикаторов и ручная публикация (только админ)

На экране сигнала админ всегда видит блок «Перевес индикаторов»: куда склоняются RSI, положение
цены в полосах Боллинджера и тренд 15м, с силой «слабый / средний / сильный». Направление есть
всегда, но это **не сигнал** — правила сигнала не выполнены. В поиске по активам у админа тоже
виден перевес по каждому активу.

Кнопки «📤 Опубликовать ВЫШЕ / НИЖЕ» доступны, пока идёт окно входа (60 с). Пост уходит в канал
в обычном формате, запись попадает в историю, а итог после экспирации считается и (если бот
подключён) публикуется автоматически — включая минусы. Решение публиковать — за вами.

## 6а. Ручная разблокировка из списка

Функции из `LOCKED_FEATURES` (по умолчанию ИИ-разбор и акции) закрыты замком 🔒. На экране замка
пользователь видит свой Telegram ID, кнопки «📋 Копировать ID» и «💬 Помощь». Он присылает ID
в поддержку, вы сами решаете, открывать ли доступ, и добавляете ID в список:

- **Вариант 1 — в коде:** `UNLOCKED_IDS: [111111111, 222222222]`, затем передеплой `index.html`.
- **Вариант 2 — в `settings.json` (удобнее):** `"UNLOCKED_IDS": [111111111, 222222222]`.
  Файл правится прямо на сайте GitHub с телефона, код трогать не нужно. Оба списка складываются.

Админы из `ADMIN_IDS` открыты всегда. Параметр `?admin_preview=1` показывает только админ-кнопки,
замки он **не** снимает.

Важно: это скрытие, а не защита. Список и код видны любому, кто откроет исходник страницы;
настоящая проверка доступа возможна только на сервере (см. «Что можно доработать»).
Не обещайте доступ «за депозит»: вы не сможете проверить это из приложения, а такие обещания
подталкивают людей рисковать деньгами.

## 6б. Реф-ссылка и доступ без правки кода (`settings.json`)

Общая для всех настройка хранится в `settings.json` рядом с `index.html`:

```json
{
  "REF_URL": "https://ваша-новая-реф-ссылка",
  "SUBID_PARAM": "sub_id",
  "SUPPORT_USERNAME": "ник_поддержки",
  "UNLOCKED_IDS": [111111111]
}
```

Пустая строка значит «взять из CONFIG». Приложение читает файл при каждом открытии.

В «⚙️ Админке»:
1. Блок «Реф-ссылка»: видно, какая ссылка сейчас у пользователей; вводите новую — сразу видно
   итоговую ссылку, есть «🔎 Проверить ссылку».
2. Блок «Ручная выдача доступа»: вводите Telegram ID → «Выдать», ✕ — снять.
   - **С Worker** — срабатывает сразу, ничего сохранять не нужно.
   - **Без Worker** — изменения попадают в черновик `settings.json`.
3. Блок «Сохранить настройки для всех»: «📋 Копировать settings.json» → «✏️ Открыть settings.json на GitHub»
   → заменить текст → *Commit changes*. Через 1–10 минут (кэш GitHub Pages) работает у всех.

## 6в. Бот без сервера: посты в канал, автопостинг, рассылка

Всё работает прямо из приложения на телефоне админа — сервер не нужен.
«⚙️ Админка» → «Бот и канал»:
1. Сделайте `@ta_signals_robot` админом канала с правом публикации.
2. Вставьте **токен бота** и канал (`@имя_канала` или `-100…`) → «Сохранить». Приложение проверит
   токен через `getMe`. Токен хранится **только в памяти этого телефона** (localStorage), в код сайта
   и на GitHub он не попадает. На другом телефоне второго админа его нужно ввести отдельно.
3. Теперь кнопки «📤 Отправить в канал / результат / итог» публикуют пост **ботом сразу в канал**,
   с кнопкой «📊 Открыть приложение».
4. «Автопостинг, пока приложение открыто» — раз в минуту проверяет EUR/USD, BTC, ETH и сам постит
   сигналы и итоги. Работает, только пока приложение открыто и экран телефона включён.
   Для круглосуточного автопостинга — Worker (раздел 7).

«Рассылка в боте»:
- Подписчик — тот, кто нажал *Start* в боте. Приложение забирает новых подписчиков через
  `getUpdates` и отвечает им приветствием (текст меняется в админке).
- Telegram хранит новые `/start` только **24 часа** — открывайте админку хотя бы раз в сутки.
- «📣 Отправить всем» — рассылка с подтверждением, ≈15 сообщений в секунду; кто заблокировал бота,
  удаляется из списка. Список подписчиков хранится на телефоне админа.
- Если для бота включён webhook (например, другим сервисом), список так не собрать — отключите webhook.

**Общая база без сервера.** Список подписчиков, сообщения для рассылки и заблокировавшие бота
хранятся в файле `ta_db.json`, который бот закрепляет в своём чате с **первым админом** из
`ADMIN_IDS` (861034642). Оба админа читают и дописывают этот файл через токен бота, поэтому список
общий. Условие: первый админ должен один раз нажать *Start* в боте. Файл не удаляйте и не
открепляйте; при каждом сохранении бот присылает новую копию без звука и удаляет старую.

**Рассылка кружков, голосовых, фото, видео, альбомов:**
1. Отправьте боту в личку (со своего админ-аккаунта) кружок, голосовое, фото, видео, альбом или текст.
2. Админка → «🔄 Обновить подписчиков» — сообщение появится в списке «Рассылка кружков, голосовых, фото».
3. Нажмите 📣 рядом с ним → подтвердите. Бот копирует сообщение всем подписчикам без пометки
   «переслано» (кружок остаётся кружком, голосовое — голосовым, альбом — альбомом).

Безопасность: токен — ключ ко всему боту. Не вводите его на чужих устройствах и не отправляйте
в чаты; если он где-то засветился — `/revoke` в @BotFather и введите новый.

## 6г. Уведомления о новых сигналах

**В приложении (для всех):** на главном экране кнопка «🔔 Включить уведомления о сигналах».
Раз в минуту приложение проверяет EUR/USD, BTC и ETH; при новом сигнале сверху появляется баннер
«🔔 ETH/USD · ▲ ВЫШЕ — Открыть», телефон вибрирует и звучит короткий сигнал. Работает, пока
приложение открыто: фоновых пушей у Mini App в Telegram нет.

**Сообщением от бота (настраивает админ):** «⚙️ Админка» → «Рассылка в боте» →
«🔔 Присылать подписчикам „Новый сигнал“ в личку». При каждом опубликованном сигнале (кнопкой
«📤 Опубликовать» или автопостингом) бот пишет подписчикам: актив, направление, экспирация, «вход до».
Это настоящее уведомление Telegram — оно приходит, даже если приложение закрыто.
Подписчик может написать боту `/stop` — и больше не получать уведомления (`/start` — снова подписаться).
Без Worker уведомления уходят, пока приложение открыто у админа; с Worker — круглосуточно
(по каналу — уже сейчас, личные уведомления через Worker — в списке доработок).

## 7. Необязательно: круглосуточный автопостинг через Cloudflare Worker

`worker.js` в репозитории — маленький сервер, который хранит токен бота у себя (в браузер он не
попадает) и умеет:
- **автопостинг**: раз в минуту проверяет EUR/USD, BTC/USD, ETH/USD по тем же правилам, что
  приложение; при сигнале сам постит «СИГНАЛ #N», а после экспирации — «#N — ПЛЮС/МИНУС/ВОЗВРАТ»;
- **пост по кнопке**: кнопки «📤 Отправить…» в приложении отправляют пост ботом сразу в канал;
- **мгновенную выдачу доступа** из админки и переключатель автопостинга;
- проверяет подпись `initData`, поэтому чужой человек не может постить от вашего имени.

Как подключить (10 минут, телефон):
1. Сделайте бота **админом канала** с правом публикации (канал → Администраторы → добавить `@ta_signals_robot`).
2. Зарегистрируйтесь на **dash.cloudflare.com** (бесплатный план).
3. *Workers & Pages* → *Create* → *Create Worker* → имя `ta-signals` → *Deploy*.
4. *Edit code* → удалите всё → вставьте содержимое
   `https://raw.githubusercontent.com/latyson/ta-signals/main/worker.js` → *Deploy*.
5. *Storage & Databases* → *KV* → *Create* → имя `ta_state`. Затем Worker → *Settings* → *Bindings* →
   *Add* → *KV namespace* → Variable name `STATE`, namespace `ta_state`.
6. Worker → *Settings* → *Variables and Secrets* → *Add*:
   | Имя | Тип | Значение |
   |---|---|---|
   | `BOT_TOKEN` | **Secret** | токен из @BotFather (новый, после `/revoke`) |
   | `CHANNEL_ID` | Text | `@имя_канала` (или `-100…` для закрытого) |
   | `ADMIN_IDS` | Text | `861034642,900500058` |
   | `APP_LINK` | Text | `https://t.me/ta_signals_robot/trade228` |
   | `ALLOWED_ORIGIN` | Text | `https://latyson.github.io` |
   Необязательно: `OPENROUTER_KEY` (**Secret**) — ИИ для всех пользователей, `AUTO_ASSETS` (`EURUSD,BTCUSD,ETHUSD`), `AUTO_EXP` (`1`, `3` или `5`), `PAYOUT` (`0.8`).
7. Worker → *Settings* → *Trigger Events* → *Add* → *Cron Triggers* → `* * * * *` (каждую минуту).
8. Скопируйте адрес Worker (`https://ta-signals.<ваш-аккаунт>.workers.dev`) и впишите в
   `CONFIG.WORKER_URL` в `index.html` (или пришлите разработчику).

Проверка: «⚙️ Админка» → «Бот и канал» → «Тестовый пост». Автопостинг можно выключить там же.

Ограничения: автопостинг работает только по активам с Binance (EUR/USD, BTC, ETH); пока по активу
не подведён итог, новый сигнал по нему не публикуется. Нумерация автопостинга своя (хранится в KV).
Токен бота никогда не вставляйте в `index.html` и не пересылайте в чаты.

## Что можно доработать

**Доступ и безопасность**
- Команды боту в личке: `/unlock 123456789`, `/ref <ссылка>`, `/auto on|off` (через webhook того же Worker).
- Реф-ссылку тоже хранить в KV Worker — смена без GitHub.
- Прокси для Twelve Data и ИИ через Worker, чтобы ключи не были видны в браузере.

**Данные**
- Праздники бирж США и форекса (сейчас в эти дни просто «Нет данных»).
- Реальные пары GBP/USD и др. через Binance нельзя, но можно добавить второй источник на случай
  лимита Twelve Data.
- Хранение истории в `Telegram.CloudStorage` — история переживёт смену телефона.

**Аналитика и честность статистики**
- Бэктест на реальных исторических свечах прямо в приложении (`?backtest=EURUSD`) — показать,
  как правила вели себя за последние недели, с учётом выплаты.
- Статистика по каждому активу и экспирации отдельно, график винрейта против безубыточного.
- Журнал «пропущенных» сигналов (вход после окна 60 сек) отдельно от вовремя открытых.

**Интерфейс**
- Telegram MainButton вместо кнопки «Анализ», CloudStorage для языка.
- Уведомление ботом в личку, когда результат готов (Worker уже есть — нужен webhook).
- Светлая тема по `Telegram.WebApp.colorScheme`.

**Уже сделано:** мини-график 60 свечей с Bollinger на экране сигнала; общая база подписчиков
для обоих админов (файл в Telegram, раздел 6в).

**Уведомления**
- Личные «🔔 Новый сигнал» из Worker круглосуточно (Worker читает ту же общую базу подписчиков).
- Подписка по активам: `/eth`, `/btc`, `/eur` — присылать только нужные.
- «Тихие часы» — не беспокоить ночью по МСК.

**Админка**
- Автопостинг итога дня по расписанию (например, в 23:55 МСК).
- Итог недели/месяца в канал.
- Статистика автопостинга по дням в админке (данные уже копятся в KV).

## Как работает сигнал (кратко)

- ВЫШЕ: закрытие 1м ниже нижней Bollinger(20,2) **и** RSI(14) < 30 **и** тренд 15м (EMA20 vs EMA50) не «вниз».
- НИЖЕ: закрытие выше верхней BB **и** RSI > 70 **и** тренд 15м не «вверх».
- Вход = open свечи после сигнальной, выход = close последней свечи экспирации. Результат считается автоматически.
- Самопроверка показывает: на случайных данных винрейт ≈ 50%. Это честный ориентир — индикаторы
  не дают гарантированного преимущества, а для безубыточности при выплате 80% нужно 55.6%.
